## 无障碍

- 状态不能只依靠颜色表达，标签文本必须保留完整含义。
- Tag 支持标准 span、ARIA、data 属性和事件，并转发 span ref。

## 避免事项

- 不要把 Tag 用作按钮或链接；交互场景应组合 Button 或原生链接。
- 避免在 Tag 中放入长句或复杂操作。
