## 组成部分

- **Attachment** — 通过标题、说明、媒体和操作 props 展示单个附件。
- **Attachment.Group** — 通过 items props 展示附件集合。

## 类型定义

### AttachmentProps

```ts
type AttachmentProps = Omit<ComponentProps<'div'>, 'children' | 'title'> & {
  title: ReactNode;
  description?: ReactNode;
  media?: ReactNode;
  mediaType?: 'icon' | 'image';
  actions?: ReactNode;
  trigger?: ReactElement;
  orientation?: 'horizontal' | 'vertical';
  size?: 'xs' | 'sm' | 'default';
  state?: 'idle' | 'uploading' | 'processing' | 'error' | 'done';
};
```

### AttachmentGroupItem

```ts
type AttachmentGroupItem = AttachmentProps & {
  key?: React.Key;
  title: ReactNode;
  description?: ReactNode;
  media?: ReactNode;
  mediaType?: 'icon' | 'image';
  actions?: ReactNode;
  trigger?: ReactElement;
  orientation?: 'horizontal' | 'vertical';
  size?: 'xs' | 'sm' | 'default';
  state?: 'idle' | 'uploading' | 'processing' | 'error' | 'done';
};
```

## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
