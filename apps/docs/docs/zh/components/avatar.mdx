{"表示人物、团队或其他实体。"}

- 需要覆盖默认、受控、禁用和窄屏状态时。

## 组成部分

- **Avatar** — 通过图片、回退内容和 badge props 展示头像。
- **Avatar.Group** — 通过 items、max 与 overlap 展示头像集合。

## 类型定义

### AvatarFallbackProps

```ts
type AvatarFallbackProps = Omit<ComponentProps<'span'>, 'children'> & {
  delay?: number;
};
```

### AvatarImageProps

```ts
type AvatarImageProps = Omit<
  ComponentProps<'img'>,
  'alt' | 'children' | 'src'
> & {
  onLoadingStatusChange?: (status: AvatarImageLoadingStatus) => void;
};
```

### AvatarImageLoadingStatus

```ts
type AvatarImageLoadingStatus = 'error' | 'idle' | 'loaded' | 'loading';
```

### AvatarGroupItem

```ts
type AvatarGroupItem = AvatarProps & {
  key?: React.Key;
  alt: string;
  src?: string;
  fallback?: ReactNode;
  fallbackProps?: AvatarFallbackProps;
  imageProps?: AvatarImageProps;
  badge?: ReactNode;
  shape?: 'circle' | 'square';
  size?: 'sm' | 'default' | 'lg';
};
```
