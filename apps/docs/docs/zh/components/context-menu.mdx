## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
