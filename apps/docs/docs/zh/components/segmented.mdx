# Segmented 分段控制器

{"在一组紧凑的视图、模式或筛选条件中选择一项。"}

## 何时使用

- 可选项数量少且需要始终可见，例如列表或看板视图、数据密度和简单筛选。
- 切换只改变一个值，不需要建立标签与内容面板的语义关系。

Segmented 不渲染内容面板。当每个选项都拥有对应的内容区域，并需要 `tab` / `tabpanel` 键盘与读屏语义时，使用 Tabs。

## 无障碍

- 组件使用单选组语义，支持 Tab 聚焦、方向键切换和表单提交。
- 纯图标标签应通过选项的 `aria-label` 提供可感知名称。
- 用户开启减少动态效果时，选中指示器会立即切换。

## 避免事项

- 不要放入大量选项；长列表应使用 Select。
- 不要用 Segmented 模拟拥有内容面板语义的 Tabs。
