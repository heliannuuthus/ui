# Select 选择器

{"从固定候选项中选择一个值，并可直接输入关键词过滤较长列表。"}

## 何时使用

- 候选项固定时使用 Select；列表较长时直接输入关键词过滤。
- 通过 options 提供平铺或分组候选项，通过受控或非受控 props 管理单选值。

Select 的值限定为字符串或数字。需要多选、标签折叠或异步搜索时，应使用单独的 Multi Select / Combobox，而不是继续扩张 Select 的属性面。
