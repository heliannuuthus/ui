# Select 选择器

{"从固定候选项中选择一个或多个值，并使用同一套交互直接过滤较长列表。"}

## 何时使用

- 候选项固定时使用 Select；列表较长时直接输入关键词过滤。
- 通过 options 提供平铺或分组候选项，通过受控或非受控 props 管理选择。

## 类型定义

### SelectClassNames

```ts
type SelectClassNames = {
  trigger?: string;
};
```

### SelectStyles

```ts
type SelectStyles = {
  trigger?: React.CSSProperties;
};
```

### SelectOption

```ts
type SelectOption<Value> = {
  disabled?: boolean;
  label: ReactNode;
  value: Value;
};
```

### SelectOptionGroup

```ts
type SelectOptionGroup<Value> = {
  label: ReactNode;
  options: readonly SelectOption<Value>[];
};
```

### SelectTriggerProps

```ts
type SelectTriggerProps = Omit<
  InputHTMLAttributes<HTMLInputElement>,
  'children' | 'className'
> & {
  children?: ReactNode;
  className?: string;
  inputRef?: Ref<HTMLInputElement>;
  showClear?: boolean;
  showTrigger?: boolean;
};
```

## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
