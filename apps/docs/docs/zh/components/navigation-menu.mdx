# Navigation Menu 导航菜单

{"组织站点或产品的主要入口，并在需要时展开带有说明和分组的丰富导航面板。"}

## 何时使用

- 一级入口需要同时展示分类、说明或推荐内容。
- 站点导航需要兼顾直接链接和可展开的内容分组。

## 示例

<NavigationMenuShowcase />

### 基础用法

{"把产品入口、资源入口和当前页面放入同一条站点导航，弹层宽度随内容平滑变化。"}

```tsx title="showcases/navigation-menu/cases/basic-usage.tsx"
import { NavigationMenu } from '@heliannuuthus/ui';

<NavigationMenu
  items={[
    {
      label: '产品',
      content: ({ Link }) => (
        <div>
          <Link href="/components">组件库</Link>
          <Link href="/tokens">设计令牌</Link>
        </div>
      ),
    },
    { label: '组件', href: '/components', active: true },
  ]}
/>;
```

### 局部导航与对齐

{"在工具栏右侧使用较小内容面板，并通过 align 控制弹层相对导航的对齐方式。"}

```tsx title="showcases/navigation-menu/cases/local-navigation-and-alignment.tsx"
import { NavigationMenu } from '@heliannuuthus/ui'

<NavigationMenu
  align="end"
  items={[
    { label: '产品', content: ({ Link }) => <Link href="/components">组件库</Link> },
    { label: '组件', href: '/components' },
  ]}
/>

<NavigationMenu
  items={items}
  orientation="vertical"
  value={value}
  onChange={setValue}
  delay={100}
  closeDelay={200}
/>
<NavigationMenu defaultValue="docs" items={items} />
```

## 类型定义

### NavigationMenuItemConfig

```ts
type NavigationMenuItemConfig = {
  active?: boolean;
  content?: ReactNode | ((slots: NavigationMenuLinkSlots) => ReactNode);
  disabled?: boolean;
  href?: string;
  label: ReactNode;
  value?: string;
};
```

### NavigationMenuLinkSlots

```ts
type NavigationMenuLinkSlots = {
  Link: NavigationMenuLinkComponent;
};
```

### NavigationMenuLinkComponent

```ts
type NavigationMenuLinkComponent = (
  props: NavigationMenuLinkProps
) => ReactNode;
```

### NavigationMenuLinkProps

```ts
type NavigationMenuLinkProps = Omit<ComponentProps<'a'>, 'children'> & {
  active?: boolean;
  children?: ReactNode;
  closeOnClick?: boolean;
};
```

## 无障碍

- 顶层入口和弹层链接支持键盘聚焦与方向键导航。
- 当前页面使用 active 状态，并保持链接文字能独立表达目标。

## 避免事项

- 不要用大菜单隐藏唯一的主要行动；高频入口应保持直接可见。
- 避免在弹层中继续嵌套第三层导航。
