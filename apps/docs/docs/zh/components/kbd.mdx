# Kbd 键盘按键

{"以键帽形式展示键盘按键和快捷键组合。"}

## 何时使用

- 解释键盘快捷方式。
- 在菜单、提示或命令面板中展示操作按键。

## 示例

<KbdShowcase />

### 基础用法

{"使用用户设备上容易识别的按键名称。"}

```tsx title="showcases/kbd/cases/basic-usage.tsx"
import { Kbd } from '@heliannuuthus/ui';

<Kbd>Enter</Kbd>;
```

### 组合快捷键

{"通过 keys 属性统一多个按键之间的间距。"}

```tsx title="showcases/kbd/cases/combination-shortcut-keys.tsx"
import { Kbd } from '@heliannuuthus/ui'

<Kbd keys={['⌘', 'K']} />
<Kbd keys={['Ctrl', 'Alt', 'Delete']} separator="·" />
```

## 无障碍

- 同时用文本解释不常见的快捷键用途。
- 针对 macOS 和 Windows 展示对应的平台按键。

## 避免事项

- Kbd 只用于展示，不应承担实际键盘事件监听。
- 不要假设所有用户都使用同一种键盘布局。
