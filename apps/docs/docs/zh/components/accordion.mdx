## 组成部分

- **Accordion** — 管理展开值并根据 items 渲染一组关联面板。
- **AccordionItem** — 描述单个条目的标识、标题、面板内容与禁用状态。
- **Accordion.Indicator** — 读取当前条目状态，并在标题起始侧或末端渲染展开指示器。

## 类型定义

### AccordionItem

```ts
type AccordionItem = {
  value: string;
  title: ReactNode;
  content: ReactNode;
  disabled?: boolean;
};
```

### AccordionIndicatorProps

```ts
type AccordionIndicatorProps = Omit<ComponentProps<'span'>, 'children'> & {
  children?: ReactNode | ((state: AccordionIndicatorState) => ReactNode);
  position?: 'start' | 'end';
};
```

### AccordionIndicatorState

```ts
type AccordionIndicatorState = {
  open?: boolean;
  disabled?: boolean;
  value?: string;
};
```
