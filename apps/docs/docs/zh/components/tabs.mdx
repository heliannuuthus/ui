# Tabs 标签页

{"在同一上下文中切换互斥内容，同时保持页面位置和任务连续性。"}

## 何时使用

- 多组内容处于同一层级，并且用户通常只需要查看其中一组。
- 切换内容不应改变页面主路径或丢失当前任务上下文。

## 示例

<TabsShowcase />

### 基础用法

{"默认样式承载概览、动态与成员数据，切换后内容区域保持稳定。"}

```tsx title="showcases/tabs/cases/basic-usage.tsx"
import { Tabs } from '@heliannuuthus/ui';

<Tabs
  defaultValue="overview"
  items={[
    { value: 'overview', label: '概览', content: <Overview /> },
    { value: 'activity', label: '动态', content: <Activity /> },
    { value: 'members', label: '成员', content: <Members /> },
  ]}
/>;
```

### 四种样式与快捷居中

{"胶囊、线型、描边和柔和样式覆盖不同层级；centered 可直接让标签列表居中。"}

```tsx title="showcases/tabs/cases/four-styles-and-quick-centering.tsx"
import { Tabs } from '@heliannuuthus/ui';

<Tabs
  defaultValue="preview"
  variant="line"
  centered
  items={[
    { value: 'preview', label: '预览', content: '实时预览当前组件。' },
    { value: 'code', label: '代码', content: '查看组件实现代码。' },
  ]}
/>;
```

### 窄容器压力测试

{"320px 与 480px 只是代表性的测试容器，不是组件断点；空间不足时隐藏原生滚动条、显示两侧导航按钮，同时保留触摸与触控板横向滑动。"}

```tsx title="showcases/tabs/cases/narrow-vessel-pressure-testing.tsx"
import { Tabs } from '@heliannuuthus/ui';

<Tabs
  animation="slide"
  defaultValue="design"
  items={[
    { value: 'design', label: '设计', content: <Design /> },
    { value: 'code', label: '开发', content: <Development /> },
  ]}
/>;
```

### 内容切换动效

{"稳定的内容视口保持边框和尺寸不动；淡入或方向滑动只作用于面板内容，系统减少动态效果时自动降级。"}

```tsx title="showcases/tabs/cases/content-switching-animation.tsx"
<Tabs
  animation="slide"
  centered
  classNames={{
    panel: 'p-8',
    viewport: 'mt-4 min-h-48 rounded-xl border',
  }}
  defaultValue="design"
  variant="soft"
  items={[
    { value: 'design', label: '设计', content: '整理组件视觉规范' },
    { value: 'code', label: '开发', content: '连接组件与业务状态' },
    { value: 'release', label: '发布', content: '完成验证并发布' },
  ]}
/>

<Tabs value={value} onChange={setValue} items={items} orientation="vertical" />
```

## 类型定义

### TabsClassNames

```ts
type TabsClassNames = {
  indicator?: string;
  list?: string;
  panel?: string;
  tab?: string;
  viewport?: string;
};
```

### TabsStyles

```ts
type TabsStyles = {
  indicator?: React.CSSProperties;
  list?: React.CSSProperties;
  panel?: React.CSSProperties;
  tab?: React.CSSProperties;
  viewport?: React.CSSProperties;
};
```

## 无障碍

- 标签列表、标签和面板之间保留正确的 ARIA 关联。
- 水平标签使用左右方向键，纵向标签使用上下方向键移动。
- 横向标签溢出时，前后按钮提供可本地化名称；触控滚动和焦点自动带出仍然可用。

## 避免事项

- 不要用 Tabs 表达有前后依赖的步骤流程。
- 标签过多时应减少分组或改用导航，不应挤压到无法辨认。
- 不要为 Tabs 硬编码设备断点；应让它服从实际父容器，并在嵌套窄空间中验证溢出行为。
