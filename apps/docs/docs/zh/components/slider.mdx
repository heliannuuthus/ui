# Slider 滑块

{"在连续或离散范围内选择数值。"}

## 何时使用

- 需要在连续或离散范围内选择数值时。
- 需要覆盖默认、受控、禁用和窄屏状态时。

## 示例

<SliderShowcase />

### 基础用法

{"使用单个滑块在明确的最小值和最大值之间选择数值。"}

```tsx title="showcases/slider/cases/basic-usage.tsx"
import { Slider } from '@heliannuuthus/ui';

<Slider aria-label="音量" defaultValue={64} min={0} max={100} />;
```

### 弹性反馈

{"透明安全区为轻微缩放与越界回弹预留空间，两端图标和文字始终保持一致反馈。"}

```tsx title="showcases/slider/cases/elastic-feedback.tsx"
import { Slider } from '@heliannuuthus/ui';
import { Volume1, Volume2 } from 'lucide-react';

<Slider
  aria-label="播放器音量"
  startIcon={<Volume1 />}
  endIcon={<Volume2 />}
  startLabel="静音"
  endLabel="最大"
  value={volume}
  onChange={setVolume}
  min={0}
  max={100}
  step={2}
/>;
```

### 范围选择

{"使用双滑块选择预算区间，并把当前值与范围边界直接展示出来。"}

```tsx title="showcases/slider/cases/range-selection.tsx"
<Slider value={range} onChange={setRange} min={0} max={100} step={2} />
```

### 垂直方向

{"为容器提供明确高度后，通过 orientation=\"vertical\" 构建纵向参数控制。"}

```tsx title="showcases/slider/cases/vertical-direction.tsx"
<Slider
  aria-label="人声电平"
  className="h-56"
  orientation="vertical"
  value={level}
  onChange={setLevel}
  min={0}
  max={100}
  step={2}
/>

<Slider
  defaultValue={[20, 80]}
  disabled={loading}
  format={{ style: 'percent' }}
  locale="en-US"
  largeStep={10}
  minStepsBetweenValues={2}
  thumbCollisionBehavior="push"
  onChangeComplete={setCommittedValue}
/>
```

## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
