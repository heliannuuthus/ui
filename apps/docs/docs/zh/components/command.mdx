# Command 命令面板

{"提供可搜索的键盘命令列表。"}

## 何时使用

- 需要从较多页面、文件、设置或操作中快速搜索并执行命令。
- 需要同时支持键盘导航、快捷键提示和模糊检索。
- 需要在页面内嵌列表与模态命令面板之间复用同一组命令数据。

## 示例

<CommandShowcase />

### 基础用法

{"通过 groups 和 options 创建可搜索的命令列表，选项负责图标、快捷键与执行回调。"}

```tsx title="showcases/command/cases/basic-usage.tsx"
import { Command } from '@heliannuuthus/ui';

<Command
  groups={[
    {
      heading: '常用命令',
      options: [
        { label: '新建文件', shortcut: '⌘N', value: 'new-file' },
        { label: '打开设置', shortcut: '⌘,', value: 'settings' },
      ],
    },
  ]}
/>;
```

### 分组与选项

{"每个 group 使用 heading 标记分组标题，并通过 options 配置命令值、标签、检索关键词、图标、快捷键、禁用状态和执行回调。"}

```tsx title="showcases/command/cases/groups-and-options.tsx"
import { Command, type CommandGroup } from '@heliannuuthus/ui'

const groups: CommandGroup[] = [
  {
    heading: 'Files',
    options: [
      {
        value: 'new-file',
        label: 'New file',
        keywords: ['create', 'document'],
        shortcut: '⌘N',
        onSelect: () => createFile(),
      },
      { value: 'open-file', label: 'Open file', disabled: true },
    ],
  },
  {
    heading: 'Preferences',
    options: [{ value: 'settings', label: 'Open settings' }],
  },
]

<Command groups={groups} />
```

### 搜索输入提示

{"placeholder 只描述搜索输入框尚未输入内容时的预期查询，不负责空结果反馈。"}

```tsx title="showcases/command/cases/search-input-placeholder.tsx"
<Command groups={groups} placeholder="Search pages, files, or settings…" />
```

### 空结果内容

{"emptyText 仅在过滤后没有匹配命令时显示，可以是纯文本，也可以是包含图标、标题和建议的 ReactNode。"}

```tsx title="showcases/command/cases/empty-result-content.tsx"
const [query, setQuery] = useState('missing command')

<Command
  groups={groups}
  inputProps={{ value: query, onChange: setQuery }}
  emptyText="No matching command"
/>
```

### 命令弹窗

{"dialog 是 Command 对通用 Dialog 的组合入口，用来把同一份命令列表放入模态层；它负责触发器、标题、说明和开关状态，groups 仍负责命令内容。"}

```tsx title="showcases/command/cases/command-dialog.tsx"
import { Button, Command } from '@heliannuuthus/ui'

<Command
  dialog={{
    trigger: <Button>Open command palette</Button>,
    title: 'Quick actions',
    description: 'Search and run a workspace action.',
  }}
  groups={groups}
/>

<Command
  value={query}
  onChange={setQuery}
  filter={filterCommand}
  label="Quick actions"
  loop
  vimBindings
  disablePointerSelection
  groups={[
    {
      heading: 'Workspace',
      options: [
        {
          value: 'open-settings',
          label: 'Open settings',
          keywords: ['preferences'],
          icon: <Settings />,
          shortcut: '⌘,',
          disabled: false,
          onSelect: openSettings,
        },
      ],
    },
  ]}
/>
<Command defaultValue="settings" groups={groups} />
```

## 组成部分

- **Command** — 渲染搜索输入、过滤结果和键盘可导航的命令列表。
- **CommandGroup** — 描述一个可选标题和该分组包含的命令选项。
- **CommandOption** — 描述单条命令的值、内容、搜索关键词、状态和执行行为。

## 类型定义

### CommandInputProps

```ts
type CommandInputProps = Omit<
  InputHTMLAttributes<HTMLInputElement>,
  'children' | 'defaultValue' | 'onChange' | 'value'
> & {
  value?: string;
  onChange?: (value: string) => void;
};
```

### CommandFilter

```ts
type CommandFilter = (
  value: string,
  search: string,
  keywords?: string[]
) => number;
```

## 无障碍

- 使用 label 为命令列表提供明确的可访问名称。
- 键盘用户可以输入关键词，并通过方向键移动、Enter 执行命令。
- 禁用命令需要使用 disabled，不要仅通过颜色表达不可用状态。

## 避免事项

- placeholder 描述可搜索内容，emptyText 说明搜索无结果，两者不要混用。
- value 管理当前命令选择；搜索关键词应通过 inputProps 管理。
- shortcut 只负责展示提示，应用仍需自行注册对应的全局快捷键。
