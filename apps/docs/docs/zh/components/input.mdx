{"通过单行、多行、组合输入和验证码承接不同复杂度的录入任务。"}

## 何时使用

- 输入单行或多行文本、带前后缀的结构化内容或固定长度验证码。
- 需要在同一输入任务中组合说明、附加动作和状态反馈。

## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
