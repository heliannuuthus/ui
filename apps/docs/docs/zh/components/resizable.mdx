# Resizable 可调整大小

{"通过可拖动分隔线调整相邻内容区域的尺寸。"}

## 何时使用

- 文件树、列表或导航需要与详情内容共享同一工作区。
- 用户需要根据当前任务主动分配相邻区域的可用空间。

## 示例

<ResizableShowcase />

### 基础用法

{"拖动文件区和预览区之间的分隔线，或聚焦分隔线后使用方向键调整宽度。"}

```tsx title="showcases/resizable/cases/basic-usage.tsx"
import { Resizable } from '@heliannuuthus/ui';
import { GripVertical } from 'lucide-react';

export const Workspace = () => {
  return (
    <Resizable
      orientation="horizontal"
      separator={<GripVertical aria-hidden />}
      items={[
        { key: 'files', panel: '文件列表', size: ['34', '24'] },
        { key: 'preview', panel: '内容预览', size: ['66', '40'] },
      ]}
    />
  );
};
```

### 纵向区域

{"设置 vertical 后可调整上下区域，适合编辑器与终端、预览与日志等场景。"}

```tsx title="showcases/resizable/cases/vertical-area.tsx"
import { Resizable } from '@heliannuuthus/ui';
import { GripHorizontal } from 'lucide-react';

export const EditorWithTerminal = () => {
  return (
    <Resizable
      className="h-96"
      orientation="vertical"
      separator={<GripHorizontal aria-hidden />}
      items={[
        {
          key: 'editor',
          panel: <section>编辑器</section>,
          size: ['64', '38'],
        },
        {
          key: 'terminal',
          panel: <section>终端</section>,
          size: ['36', '20'],
        },
      ]}
    />
  );
};
```

### 尺寸约束与分隔线覆盖

{"size 集中表达初始、最小和最大尺寸；item 可覆盖默认分隔线，并通过 onResize 获取实时尺寸。"}

```tsx title="showcases/resizable/cases/size-constraints-and-divider-overrides.tsx"
import { useState } from 'react';
import { Resizable } from '@heliannuuthus/ui';
import { GripVertical } from 'lucide-react';

export const ConstrainedWorkspace = () => {
  const [navigationSize, setNavigationSize] = useState(24);

  return (
    <Resizable
      className="h-80"
      separator={({ index }) => <span>{index + 1}</span>}
      items={[
        {
          key: 'navigation',
          panel: <aside>导航 · {navigationSize}%</aside>,
          size: ['24', '18', '34'],
          collapsible: true,
          collapsedSize: 0,
          separator: <GripVertical aria-hidden />,
          onResize: (size) => setNavigationSize(Math.round(size.asPercentage)),
        },
        {
          key: 'canvas',
          panel: <main>画布</main>,
          size: ['52', '36'],
        },
        {
          key: 'inspector',
          panel: <aside>属性</aside>,
          size: ['24', '18', '34'],
          collapsible: true,
          collapsedSize: 0,
        },
      ]}
    />
  );
};

<Resizable
  items={items}
  separator={({ itemKey, nextItemKey, orientation }) => (
    <span>
      {itemKey} · {nextItemKey} · {orientation}
    </span>
  )}
/>;
```

## 类型定义

### ResizableClassNames

```ts
type ResizableClassNames = {
  panel?: string;
  separator?: string;
};
```

### ResizableStyles

```ts
type ResizableStyles = {
  panel?: React.CSSProperties;
  separator?: React.CSSProperties;
};
```

### PanelSize

```ts
type PanelSize = {
  asPercentage: number;
  inPixels: number;
};
```

### ResizableSeparator

```ts
type ResizableSeparator =
  ReactNode | ((props: ResizableSeparatorRenderProps) => ReactNode);
```

## 无障碍

- 分隔线保持可聚焦，并支持方向键调整相邻区域尺寸。
- separator 提供的纯装饰内容应使用 aria-hidden。
- items 中的导航和内容仍需使用各自正确的语义结构。

## 避免事项

- 不要让任一区域缩小到内容无法理解或操作的程度。
- 不要在 separator 中嵌套按钮等可聚焦控件，以免与分隔线的键盘交互冲突。
- 移动端空间不足时，应评估是否改用纵向排列或折叠导航。
