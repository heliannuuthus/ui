# Pagination 分页

{"在分段数据集合之间导航，并明确当前页、相邻页和数据范围。"}

## 何时使用

- 完整数据无法在一个视图中高效加载或理解。
- 用户需要在当前位置附近跳转，或返回之前浏览的结果页。

## 类型定义

### PaginationClassNames

```ts
type PaginationClassNames = {
  content?: string;
  control?: string;
  ellipsis?: string;
  item?: string;
  pageSize?: string;
  quickJumper?: string;
  summary?: string;
};
```

### PaginationStyles

```ts
type PaginationStyles = {
  content?: React.CSSProperties;
  control?: React.CSSProperties;
  ellipsis?: React.CSSProperties;
  item?: React.CSSProperties;
  pageSize?: React.CSSProperties;
  quickJumper?: React.CSSProperties;
  summary?: React.CSSProperties;
};
```

### PaginationAriaLabels

```ts
type PaginationAriaLabels = {
  first?: string;
  last?: string;
  more?: string;
  navigation?: string;
  next?: string;
  page?: (page: number) => string;
  pageSize?: string;
  previous?: string;
  quickJumper?: string;
};
```

### PaginationAriaLabelContext

```ts
type PaginationAriaLabelContext = {
  page: number | null;
  selected: boolean;
  type: PaginationItemType;
};
```

### PaginationItemType

```ts
type PaginationItemType =
  | 'page'
  | 'first'
  | 'last'
  | 'next'
  | 'previous'
  | 'ellipsis-start'
  | 'ellipsis-end';
```

### PaginationQuickJumperOptions

```ts
type PaginationQuickJumperOptions = {
  goButton?: ReactNode;
  label?: ReactNode;
  suffix?: ReactNode;
};
```

### PaginationRenderItemProps

```ts
type PaginationRenderItemProps = {
  disabled: boolean;
  originalElement: ReactElement;
  page: number | null;
  selected: boolean;
  type: PaginationItemType;
};
```

### PaginationSimpleOptions

```ts
type PaginationSimpleOptions = {
  readOnly?: boolean;
};
```

### PaginationSize

```ts
type PaginationSize = 'sm' | 'default' | 'lg';
```

## 无障碍

- 当前页使用 aria-current，上一页和下一页保留明确的可访问名称。
- 不可用的边界操作同时设置 aria-disabled 并阻止导航。

## 避免事项

- 不要一次展示所有页码；长范围应围绕当前页进行压缩。
- 如果数据天然适合连续浏览，应评估加载更多或虚拟滚动。
