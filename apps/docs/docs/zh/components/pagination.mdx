# Pagination 分页

{"在分段数据集合之间导航，并明确当前页、相邻页和数据范围。"}

## 何时使用

- 完整数据无法在一个视图中高效加载或理解。
- 用户需要在当前位置附近跳转，或返回之前浏览的结果页。

## 无障碍

- 当前页使用 aria-current，上一页和下一页保留明确的可访问名称。
- 不可用的边界操作同时设置 aria-disabled 并阻止导航。

## 避免事项

- 不要一次展示所有页码；长范围应围绕当前页进行压缩。
- 如果数据天然适合连续浏览，应评估加载更多或虚拟滚动。
