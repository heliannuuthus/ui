# Date Picker 日期与时间选择器

{"选择日期、日期时间或时间，并为每种精度提供对应的范围选择器。"}

## 何时使用

- 只关心自然日时使用 `DatePicker`，需要起止日期时使用 `DateRangePicker`。
- 事件精确到分钟时使用 `DateTimePicker` 或 `DateTimeRangePicker`。
- 时间与具体日期无关时使用 `TimePicker` 或 `TimeRangePicker`，值保持为不带时区的 `HH:mm` 字符串。

日期与日期时间使用原生 `Date`；所有范围选择器统一使用 `[start, end]` 二元组。组件名称直接表达值的精度和单值/范围语义，不需要组合 `mode`、`showTime` 等条件属性。

## 无障碍

- 日期选择保留日历网格、键盘导航和焦点管理；范围起止状态由日历语义表达。
- 为没有可见 `<label>` 的触发器设置 `aria-label`；`TimeRangePicker.labels` 分别命名开始与结束输入。

## 避免事项

- 不要用 `TimePicker` 表达绝对时间点；需要日期或时区语义时使用 DateTime 组件并在业务层明确时区。
- 不要交换范围二元组的顺序；第一项始终是开始值，第二项始终是结束值。
