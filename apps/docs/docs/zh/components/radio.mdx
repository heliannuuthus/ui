# Radio 单选框

{"使用 Radio 表达单个选项，并通过 Radio.Group 组织互斥选择。"}

## 何时使用

- 候选项较少，并希望用户直接看到、比较所有选项。
- 一组选项只允许选中一个值。

## 组成部分

- **Radio** — 表达单个互斥选项。
- **Radio.Group** — 通过 options props 管理互斥选择。
