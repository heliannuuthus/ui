# Carousel 轮播

{"横向浏览同级内容，始终提供景深动效，并支持点位插槽、自动播放、首尾循环和自定义翻页器。"}

## 何时使用

- 同一层级有多张重点内容卡片，但当前区域只适合突出展示一项。
- 需要轮播营销亮点、版本更新或媒体内容，并允许用户主动前后浏览。

## 在轮播项内读取控制器

在 Carousel 内渲染的组件（例如轮播项组件）中，从 `@heliannuuthus/ui` 导入 `useCarousel`。`useCarousel()` 返回当前 `CarouselControls`，并随轮播状态更新；在 Carousel 外调用会抛错。外部控制器使用 `ref`；分页区域的控制器可使用 `pagination.render`。

| 控制器成员 | 含义 |
| --- | --- |
| `canScrollNext` | 当前是否可以向后翻页。 |
| `canScrollPrev` | 当前是否可以向前翻页。 |
| `page` | 当前页码，从一开始。 |
| `playing` | 当前是否正在自动播放。 |
| `pages` | 可用页数。 |
| `index` | 当前滚动吸附点索引，从零开始。 |
| `snaps` | 当前滚动吸附点位置。 |
| `pause()` | 暂停自动播放。 |
| `play()` | 恢复已配置的自动播放。 |
| `scrollNext()` | 向后翻页。 |
| `scrollPrev()` | 向前翻页。 |
| `scrollTo(index)` | 跳转到从零开始的滚动吸附点索引。 |

没有可用页面时，`pagination.render` 收到的 `page` 为 `0`。
暂停、少于两页或在未循环时到达末页，`playing` 均为 `false`。

## 无障碍

- 轮播区域、幻灯片、前后按钮和页码点均保留可识别的语义与键盘操作。
- 未按修饰键时可用左右方向键切换；输入框、文本域、选择框和可编辑内容保留原生按键行为。在 onKeyDown 中调用 preventDefault 可取消轮播导航。
- 开启自动播放后，动态内容不会持续触发读屏播报；系统要求减少动态效果时会停止自动播放和景深过渡。

## 避免事项

- 不要用自动播放承载必须阅读或必须操作的内容，用户仍应能通过箭头和页码点主动导航。
- 自动播放默认悬停暂停；若关闭 pauseOnHover，需要提供其他清晰的暂停方式。
- 单屏塞入过多文字会让轮播难以扫读，内容较长时改用列表或分页。
