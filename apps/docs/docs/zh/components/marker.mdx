# Marker 标记

{"标记连续内容中的分段位置或状态。"}

## 何时使用

- 在连续内容中标记日期、未读边界、状态切换或可跳转位置。
- 需要一条带文字或图标的轻量分隔规则时使用。

## 无障碍

- 装饰性图标会自动从辅助技术中隐藏，状态含义必须同时写入 content。
- 需要跳转时传入 href，让组件保留原生链接语义和键盘操作。

## 避免事项

- 不要用 Marker 表达具有节点、连接线和顺序关系的完整时间线。
- 不要用颜色或图标单独表达状态，也不要把长段说明塞进标记文字。
