# Toggle 切换按钮

{"使用 Toggle 切换单个工具状态，并通过 Toggle.Group 管理工具组选项。"}

## 何时使用

- 工具栏中的一个状态需要立即开启或关闭。
- 一组紧密相关的工具需要共享单选或多选状态与键盘导航。

## 组成部分

- **Toggle** — 表达单个可按下、可释放的工具状态。
- **Toggle.Group** — 通过 items props 管理单选或多选工具组。

## 无障碍

- 保留底层语义、焦点管理与键盘交互。
- 为触发器、图标和状态提供可感知名称。

## 避免事项

- 不要移除焦点样式或绕过状态属性。
- 不要写死业务文案、尺寸和产品状态。
