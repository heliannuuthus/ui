# Checkbox 复选框

{"使用 Checkbox 标记单个可提交选择，并通过 Checkbox.Group 管理多选值。"}

## 何时使用

- 独立状态需要用户确认后再随表单提交。
- 一组可见选项允许同时选中多个值。

## 组成部分

- **Checkbox** — 表达单个布尔选择。
- **Checkbox.Group** — 通过 options props 管理多个选择值。

```ts

```

```ts
type CheckboxOption = {
  className?: string;
  disabled?: boolean;
  label: ReactNode;
  value: string;
  variant?: 'default' | 'task';
};
```
