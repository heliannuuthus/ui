# 按需导入

组件统一从包根入口按名称导入。构建工具根据实际引用执行 Tree Shaking；不要使用组件子路径。

```tsx
import { Button, Form, Input } from '@heliannuuthus/ui';
```

## JavaScript 按需，CSS 一次导入

这里有两个容易混淆的概念：

- JavaScript 是按需打包的。未被引用的组件不会因为根入口而自动进入业务包。
- CSS 是完整静态文件。应用入口只导入一次，异步路由中的组件也能立即获得样式。

```tsx title="main.tsx"
import '@heliannuuthus/ui/styles.css';
import './app.css';
```

完整 CSS 避免了异步页面切换时的样式闪烁，也让 Portal、焦点规则和跨组件 Token 保持一致。它不是运行时 CSS，也不要求业务项目扫描组件库源码。

## 为什么不使用组件子路径

`@heliannuuthus/ui/button` 等路径属于构建产物的内部组织，不是公共协议。绕过根入口会让版本升级、类型声明和打包验证失去统一边界。

```tsx
// 推荐
import { Button } from '@heliannuuthus/ui';

// 不要依赖私有路径
// import { Button } from '@heliannuuthus/ui/button';
```

## 其他根导出

工具函数和类型同样从公共根入口导入：

```tsx
import { buttonVariants, cn, type ButtonProps } from '@heliannuuthus/ui';

const actionClassName = cn(
  buttonVariants({ variant: 'outline', size: 'sm' }),
  'w-full'
);
```

| 导出 | 契约 |
| --- | --- |
| `cn(...inputs)` | 合并条件类名字符串、数组和对象，再处理冲突的 Tailwind 工具类，返回字符串。 |
| `buttonVariants(options?)` | 根据 `variant`、`size` 和可选的 `className` 返回 Button 类名；默认分别为 `default` 与 `md`。 |
| `markerVariants(options?)` | 根据 `variant`（`default`、`separator` 或 `border`）和可选的 `className` 返回 Marker 类名。 |
| `tabsListVariants(options?)` | 根据 `variant`（`default`、`line`、`outline` 或 `soft`）和可选的 `className` 返回标签列表类名；默认 `default`。 |
| `toggleVariants(options?)` | 根据 `variant`（`default` 或 `outline`）和可选的 `className` 返回 Toggle 类名；默认 `default`。 |
| `navigationMenuTriggerStyle()` | 返回导航菜单触发器的类名字符串，不接收参数。 |
| `useIsMobile()` | 返回视口是否小于 `768px`，并订阅断点变化。服务端渲染与客户端首帧返回 `false`，挂载后更新；需要在 hydration 前正确布局时使用 CSS 媒体查询。 |

样式工厂只返回类名，不提供交互、无障碍语义、Provider 默认值或样式表加载。需要这些行为时优先使用对应组件。表单 Hook 见 [Form](/zh/components/form)，`useProvider` 见 [全局 Provider](/zh/docs/provider)，`useCarousel` 见 [Carousel](/zh/components/carousel)。

## 构建工具要求

项目需要支持 ESM 与现代 Tree Shaking。Vite、Rspack、Webpack、Rollup、Parcel 和现代 Next.js 均可按常规方式使用。不要为组件库额外增加 Babel 按需导入插件。

## 检查包体积

如果产物异常增大，先检查：

1. 是否把整个命名空间作为运行时对象传递。
2. 是否同时加载了多个版本的 React 或组件库。
3. 是否在服务端与客户端入口重复引入业务 polyfill。
4. 构建是否启用了生产模式和 Tree Shaking。

CSS 体积与组件引用数量不是线性关系；评估时应分别观察 JavaScript chunk、共享 CSS 和缓存命中率。
