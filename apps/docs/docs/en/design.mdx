# Design

Heliannuuthus UI keeps product semantics outside the primitive layer. Components use semantic tokens, preserve native and Radix accessibility, and expose controlled and uncontrolled state where the interaction needs both.

## Principles

- Prefer composition over boolean-prop proliferation.
- Keep public naming, types, events, refs, states and extension points stable.
- Use semantic CSS variables instead of product-specific colors.
- Cover disabled, loading, empty, error, long-content and narrow-layout states.
- Import every public component from `@heliannuuthus/ui`.
