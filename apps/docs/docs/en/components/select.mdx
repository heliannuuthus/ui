# Select

{"Select one or more values ​​from fixed candidates and filter longer lists directly using the same set of interactions."}

## When to use

- Use Select when the candidates are fixed; directly enter keywords to filter when the list is long.
- Provide tiling or grouping candidates via options and manage selection via controlled or uncontrolled props.

## Examples

<SelectShowcase />

### Basic usage

{"When there are many candidates and the user knows the keywords, they can directly enter to filter, clear and re-select."}

```tsx title="showcases/select/cases/basic-usage.tsx"
import { Select } from '@heliannuuthus/ui';

<Select
  value={value}
  onChange={setValue}
  placeholder="Search for members…"
  showClear
  emptyText="Member not found"
  options={members.map((member) => ({ label: member, value: member }))}
/>;
```

### Group selection

{"The same Select is used when candidates are fixed, with groupings, separators, and disabled items clarifying the list structure."}

```tsx title="showcases/select/cases/group-selection.tsx"
import { Select } from '@heliannuuthus/ui'

<Select
  value={value}
  onChange={setValue}
  placeholder="Select workspace"
  options={groups.map((group) => ({
    label: group.label,
    options: group.items.map((item) => ({
      label: item.label,
      value: item,
      disabled: item.disabled,
    })),
  }))}
/>

<Select
  searchValue={query}
  onSearch={setQuery}
  multiple
  disabled={loading}
  locale="en-US"
  options={options}
/>
<Select defaultOpen defaultSearchValue="platform" options={options} />
```

```ts

```

### SelectOption

```ts
type SelectOption<Value> = {
  disabled?: boolean;
  label: ReactNode;
  value: Value;
};
```

### SelectOptionGroup

```ts
type SelectOptionGroup<Value> = {
  label: ReactNode;
  options: readonly SelectOption<Value>[];
};
```

### SelectTriggerProps

```ts
type SelectTriggerProps = Omit<
  InputHTMLAttributes<HTMLInputElement>,
  'children' | 'className'
> & {
  children?: ReactNode;
  className?: string;
  inputRef?: Ref<HTMLInputElement>;
  showClear?: boolean;
  showTrigger?: boolean;
};
```

## Accessibility

- Preserves underlying semantics, focus management, and keyboard interaction.
- Provide sensible names for triggers, icons, and states.

## Avoid

- Don't remove focus styles or bypass state properties.
- Don’t write down business copy, dimensions, and product status.
