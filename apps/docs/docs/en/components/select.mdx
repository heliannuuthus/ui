# Select

{"Select one value from fixed candidates and filter longer lists by typing."}

## When to use

- Use Select when the candidates are fixed; directly enter keywords to filter when the list is long.
- Provide flat or grouped candidates through options and manage a single value with controlled or uncontrolled props.

Select values are limited to strings and numbers, with one selected value and local option filtering. Multiple values, tag collapsing, and asynchronous search are outside the current Select contract.

Use `value={null}` for an explicitly empty controlled selection. A controlled value with no matching option shows the placeholder. Inside `Form.Field`, a field that is uninitialized or reset to an empty value remains empty until a value is selected; it does not retain the previous option.
