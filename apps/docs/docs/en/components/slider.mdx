# Slider

{"Select a numeric value in a continuous or discrete range."}

## When to use

- Primary use: Select a numeric value in a continuous or discrete range.
- When you need to override the default, controlled, disabled and narrow screen states.

Without `value` or `defaultValue`, Slider renders one thumb at `min` (default `0`). Supply an array for a range. Inside `Form.Field`, initialize the value through the form rather than the child control's `defaultValue`. `aria-label`, `aria-labelledby`, and `aria-describedby` apply to every focusable range input; `Form.Field` supplies its label and description relationships automatically.
