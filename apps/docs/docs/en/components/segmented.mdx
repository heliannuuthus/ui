# Segmented

{"Select one compact view, mode, or filter from a small visible set."}

## When to use

- A short set of choices should remain visible, such as list or board views, data density, or a simple filter.
- Switching changes one value without establishing a semantic relationship between labels and content panels.

Segmented does not render content panels. Use Tabs when every choice owns a corresponding content region and requires `tab` / `tabpanel` keyboard and screen-reader semantics.

## Accessibility

- The component uses radio-group semantics with Tab focus, arrow-key selection, and form submission support.
- Give icon-only labels an accessible name through the option's `aria-label`.
- The selected indicator switches immediately when the user prefers reduced motion.

## Avoid

- Don't place a large number of choices inside Segmented; use Select for long lists.
- Don't use Segmented to imitate Tabs when the choices own semantic content panels.
