# Form

{"Uses Form.Field to connect data-entry controls, validation state, and submission behavior consistently."}

## When to use

- Organizes labels, controls, descriptions, and errors consistently.
- Lets built-in data-entry controls connect field values, validation state, and submission automatically.

## Component parts

- **Form** — Renders a native form and connects a Form.useForm instance.
- **Form.useForm** — Creates a typed form instance and manages the complete form state.
- **Form.Field** — Binds built-in controls automatically and organizes labels, descriptions, and validation errors.
