# Radio

{"Use Radio to express individual options, and Radio.Group to organize mutually exclusive choices."}

## When to use

- There are fewer candidates, and you want users to see and compare all options directly.
- A set of options allows only one value to be selected.

## Examples

<RadioShowcase />

### Basic usage

{"Conventional text options use options first, and Radio.Group generates labels and values ​​uniformly."}

```tsx title="showcases/radio/cases/basic-usage.tsx"
import { Radio } from '@heliannuuthus/ui';

<Radio.Group
  value={delivery}
  onChange={setDelivery}
  options={[
    { label: 'email notification', value: 'email' },
    { label: 'in-site notification', value: 'inbox' },
    { label: 'No notification', value: 'none' },
  ]}
/>;
```

### Plan radio button

{"Expand mutually exclusive options into an entire row of clickable cards while retaining native radio-select semantics."}

```tsx title="showcases/radio/cases/plan-radio-button.tsx"
import { Radio } from '@heliannuuthus/ui'

<Radio.Group
  value={delivery}
  onChange={setDelivery}
  options={[
    { label: 'email notification', value: 'email' },
    { label: 'in-site notification', value: 'inbox' },
  ]}
/>

<Radio
  value="daily"
  disabled
  classNames={{ control: 'border-primary' }}
  styles={{ label: { fontWeight: 600 } }}
>
  Daily
</Radio>
<Radio.Group defaultValue="daily" disabled gap={16} options={options} />
```

## Component parts

- **Radio** — Expresses a single mutually exclusive option.
- **Radio.Group** — Mutually exclusive selections are managed via options props.

## Type definitions

### RadioClassNames

```ts
type RadioClassNames = {
  control?: string;
  label?: string;
};
```

### RadioStyles

```ts
type RadioStyles = {
  control?: React.CSSProperties;
  label?: React.CSSProperties;
};
```

### RadioOption

```ts
type RadioOption<Value = string> = {
  className?: string;
  disabled?: boolean;
  label: ReactNode;
  value: Value;
};
```
