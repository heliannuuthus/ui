# Avatar

{"Represents a person, team, or other entity."}

## When to use

- Primary use: Represents a person, team, or other entity.
- When you need to override the default, controlled, disabled and narrow screen states.

## Examples

<AvatarShowcase />

### Basic usage

{"shape switches between circle and rounded-square avatars, with each shape shown as an independent case."}

```tsx title="showcases/avatar/cases/basic-usage.tsx"
import { Avatar } from '@heliannuuthus/ui'

<Avatar alt="Lin Mo" fallback="Lin" shape="circle" size="lg" />
<Avatar alt="Monday" fallback="Week" shape="square" size="lg" />
```

### Avatar sizes

{"size provides small, medium, and large avatars while scaling text and status indicators with them."}

```tsx title="showcases/avatar/cases/avatar-sizes.tsx"
<Avatar size="sm" alt="Lin Mo" fallback="L" />
<Avatar size="default" alt="Lin Mo" fallback="L" />
<Avatar size="lg" alt="Lin Mo" fallback="L" />
```

### Image and fallback content

{"src provides the avatar image; fallback is shown when loading fails, while imageProps and fallbackProps configure loading callbacks and delay."}

```tsx title="showcases/avatar/cases/image-and-fallback-content.tsx"
<Avatar
  alt="Lin Mo"
  src="/avatars/lin.png"
  fallback="L"
  fallbackProps={{ delay: 200 }}
  imageProps={{ onLoadingStatusChange: setStatus }}
/>
```

### Impression caps and overlap

{"max limits the number of visible avatars and automatically generates +N; overlap uses pixel values ​​to control how compact the grouping is."}

```tsx title="showcases/avatar/cases/impression-caps-and-overlap.tsx"
import { Avatar } from '@heliannuuthus/ui';

<Avatar.Group
  items={members.map((member) => ({
    key: member.id,
    alt: member.name,
    fallback: member.initials,
  }))}
  max={4}
  overlap={8}
  size="lg"
/>;
```

### Custom overflow count

{"renderCount receives the hidden count and replaces the default +N while inheriting the group shape and size."}

```tsx title="showcases/avatar/cases/custom-overflow-count.tsx"
<Avatar.Group
  items={members}
  max={3}
  renderCount={(count) => <Tag>+{count}</Tag>}
  shape="square"
  size="lg"
/>
```

### Composed with Tag and Badge

{"The badge slot accepts Tag status labels or Badge notification indicators and keeps them anchored to the avatar corner."}

```tsx title="showcases/avatar/cases/composed-with-tag-and-badge.tsx"
import { Avatar, Badge } from '@heliannuuthus/ui';

<Avatar
  alt="Chen Xu"
  badge={<Badge indicator={8} indicatorLabel="8 unread messages" />}
  fallback="Chen"
  size="lg"
/>;
```

## Component parts

- **Avatar** — Display avatars via images, fallback content, and badge props.
- **Avatar.Group** — Display the avatar collection through items, max and overlap.

## Type definitions

### AvatarFallbackProps

```ts
type AvatarFallbackProps = Omit<ComponentProps<'span'>, 'children'> & {
  delay?: number;
};
```

### AvatarImageProps

```ts
type AvatarImageProps = Omit<
  ComponentProps<'img'>,
  'alt' | 'children' | 'src'
> & {
  onLoadingStatusChange?: (status: AvatarImageLoadingStatus) => void;
};
```

### AvatarImageLoadingStatus

```ts
type AvatarImageLoadingStatus = 'error' | 'idle' | 'loaded' | 'loading';
```

### AvatarGroupItem

```ts
type AvatarGroupItem = AvatarProps & {
  key?: React.Key;
  alt: string;
  src?: string;
  fallback?: ReactNode;
  fallbackProps?: AvatarFallbackProps;
  imageProps?: AvatarImageProps;
  badge?: ReactNode;
  shape?: 'circle' | 'square';
  size?: 'sm' | 'default' | 'lg';
};
```
