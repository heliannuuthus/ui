# Breadcrumb

{"Display the current location and upper-level path, and provide a quick return entrance when the level is deep."}

## When to use

- There are more than three levels of stable information levels on the page.
- Users need to understand their current location and return to any previous page.

## Examples

<BreadcrumbShowcase />

### Basic usage

{"Breadcrumbs are placed before the page title, and the last level only indicates the current location and no longer provides a link."}

```tsx title="showcases/breadcrumb/cases/basic-usage.tsx"
import { Breadcrumb } from '@heliannuuthus/ui';

const items = [
  { label: 'Home', href: '/' },
  { label: 'component', href: '/components' },
  { label: 'Navigation', href: '/components/navigation-menu' },
  { label: 'Breadcrumb' },
];

export const PageBreadcrumb = () => {
  return <Breadcrumb items={items} icon />;
};
```

### Deep path collapse

{"When the path is too long, only the middle level will be collapsed, and the starting point, direct parent, and current page will be retained as positioning anchor points."}

```tsx title="showcases/breadcrumb/cases/deep-path-collapse.tsx"
import { Breadcrumb } from '@heliannuuthus/ui';

<Breadcrumb
  items={releasePath}
  icon
  collapse={{ maxItems: 4, before: 1, after: 2 }}
/>;
```

### Node menus and visual styles

{"Drop-down nodes are used to switch sibling positions; separators and styles only change the visual expression, not the path semantics."}

```tsx title="showcases/breadcrumb/cases/node-menus-and-visual-styles.tsx"
import { Breadcrumb } from '@heliannuuthus/ui'

<Breadcrumb items={itemsWithMenu} />
<Breadcrumb items={items} variant="underline" separator="slash" />
<Breadcrumb items={items} variant="pill" separator="dot" size="sm" />
```

## Type definitions

### BreadcrumbCollapseOptions

```ts
type BreadcrumbCollapseOptions = {
  maxItems: number;
  before?: number; // default: 1
  after?: number; // default: 2
  label?: string;
};
```

### BreadcrumbItem

```ts
type BreadcrumbItem = {
  label: ReactNode;
  href?: string;
  icon?: ReactNode;
  disabled?: boolean;
  menu?: BreadcrumbMenuItem[];
  separator?: BreadcrumbSeparator;
  onClick?: MouseEventHandler<HTMLAnchorElement>;
};
```

### BreadcrumbMenuItem

```ts
type BreadcrumbMenuItem = {
  label: ReactNode;
  href?: string;
  icon?: ReactNode;
  disabled?: boolean;
  onSelect?: () => void;
};
```

### BreadcrumbSeparator

```ts
type BreadcrumbSeparator = 'chevron' | 'slash' | 'dot' | ReactNode;
```

## Accessibility

- Use a nav with a breadcrumb name for the root node and an ordered list for the path.
- The current page uses aria-current, and the visual separators do not enter the screen reading order.
- Folding items and hierarchical menus support keyboard opening and navigation.

## Avoid

- Don’t add breadcrumbs that have no navigational value when you only have one or two levels of pages.
- Avoid showing more than five visible levels; deep paths should be collapsed using collapse.
