# Date Picker

{"Select dates, date-times, or times, with a matching range picker for every precision."}

## When to use

- Use `DatePicker` for a calendar day and `DateRangePicker` for start and end dates.
- Use `DateTimePicker` or `DateTimeRangePicker` when an event must be precise to the minute.
- Use `TimePicker` or `TimeRangePicker` when the time is independent of a date. Their values remain timezone-free `HH:mm` strings.

Date and date-time pickers use native `Date` values. Every range picker uses the same `[start, end]` tuple. Component names state both precision and single/range semantics, so consumers do not need to coordinate conditional `mode` or `showTime` props.

## Accessibility

- Date selection preserves calendar-grid semantics, keyboard navigation, and focus management. The calendar communicates range boundaries.
- Set `aria-label` when a trigger has no visible `<label>`. `TimeRangePicker.labels` names its start and end inputs separately.

## Avoid

- Do not use `TimePicker` for an absolute instant. Use a DateTime picker and define time-zone semantics in the product layer.
- Do not reverse the range tuple: the first item is always the start and the second is always the end.
