# Date Picker

{"Select individual dates via inline calendar or pop-up trigger."}

## When to use

- Primary use: Select individual dates via inline calendar or pop-up trigger.
- When you need to override the default, controlled, disabled and narrow screen states.

## Examples

<DatePickerShowcase />

### Basic usage

{"When you need to continuously view the month and scheduling context, use the inline display format and provide synchronous feedback on the selection results."}

```tsx title="showcases/date-picker/cases/basic-usage.tsx"
const [date, setDate] = useState<Date>()

<DatePicker display="inline" value={date} onChange={setDate} />
```

### Release regularly

{"Select or clear Publish Date in the compact settings row, fit form and filter."}

```tsx title="showcases/date-picker/cases/release-regularly.tsx"
<DatePicker
  value={date}
  onChange={setDate}
  placeholder="Select publication date"
/>

<DatePicker defaultValue={new Date()} disabled />
<DatePicker calendarProps={{ fixedWeeks: true }} />
```
