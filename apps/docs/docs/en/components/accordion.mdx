## Component parts

- **Accordion** — Manage open values and render a set of related panels from items.
- **AccordionItem** — Describe one item’s identifier, title, panel content, and disabled state.
- **Accordion.Indicator** — Read the current item state and render an expansion indicator at the start or end of the title.

- Preserves underlying semantics, focus management, and keyboard interaction.
- Provide sensible names for triggers, icons, and states.

- Don’t write down business copy, dimensions, and product status.
