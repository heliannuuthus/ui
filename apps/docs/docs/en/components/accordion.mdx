# Accordion

{"Expand a set of vertically arranged content areas as needed."}

## When to use

- Primary use: Expand a set of vertically arranged content areas as needed.
- When you need to override the default, controlled, disabled and narrow screen states.

## Examples

<AccordionShowcase />

### Single item expansion

{"By default, only one item is open at a time; opening another item closes the previous one."}

```tsx title="showcases/accordion/cases/single-item-expansion.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion
  defaultValue={['preflight']}
  items={[
    {
      value: 'preflight',
      title: 'Preflight results',
      content: 'All 42 checks passed.',
    },
    {
      value: 'rollback',
      title: 'Rollback plan',
      content: 'Switch back to the previous version if an issue occurs.',
    },
  ]}
/>;
```

### Multiple expansion

{"Set multiple to allow several items to remain open at the same time."}

```tsx title="showcases/accordion/cases/multiple-expansion.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion
  defaultValue={['preflight', 'rollback']}
  multiple
  items={[
    {
      value: 'preflight',
      title: 'Preflight results',
      content: '42 checks passed. ',
    },
    {
      value: 'rollback',
      title: 'Rollback plan',
      content: 'Switch back to the previous version in case of exception. ',
    },
  ]}
/>;
```

### controlled state

{"value represents the currently expanded items, and onChange receives the complete value array after user interaction."}

```tsx title="showcases/accordion/cases/controlled-state.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion items={items} value={value} onChange={setValue} />;
```

### Default indicator

{"Omit indicator to show the default arrow at the end of the title and rotate it with the open state."}

```tsx title="showcases/accordion/cases/default-indicator.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion
  defaultValue={['deployment']}
  items={[
    {
      value: 'deployment',
      title: 'Deployment strategy',
      content: 'Roll out to 10% first, observe, then release to everyone.',
    },
  ]}
/>;
```

### Start position

{"Use Accordion.Indicator position to place the default arrow at the start of the title."}

```tsx title="showcases/accordion/cases/start-position.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion
  indicator={<Accordion.Indicator position="start" />}
  items={items}
/>;
```

### State function indicator

{"Use Accordion.Indicator to set the position in one place. Its children state function receives the current item’s open, disabled, and value state so the caller controls what is rendered."}

```tsx title="showcases/accordion/cases/state-function-indicator.tsx"
import { Accordion } from '@heliannuuthus/ui';
import { Minus, Plus } from 'lucide-react';

<Accordion
  defaultValue={['deployment']}
  indicator={
    <Accordion.Indicator position="start">
      {({ open }) => (open ? <Minus /> : <Plus />)}
    </Accordion.Indicator>
  }
  items={[
    {
      value: 'deployment',
      title: 'Deployment strategy',
      content: 'Roll out to 10% first, observe, then release to everyone.',
    },
  ]}
/>;
```

### Disable one item

{"Set disabled on an AccordionItem to prevent trigger interaction for that item only."}

```tsx title="showcases/accordion/cases/disable-one-item.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion
  items={[
    {
      value: 'preflight',
      title: 'Preflight results',
      content: 'All 42 checks passed.',
      disabled: true,
    },
    {
      value: 'rollback',
      title: 'Rollback plan',
      content: 'Switch back to the previous version if an issue occurs.',
    },
  ]}
/>;
```

### Disable the entire component

{"Set disabled on Accordion to prevent every item from opening or closing."}

```tsx title="showcases/accordion/cases/disable-the-entire-component.tsx"
import { Accordion } from '@heliannuuthus/ui';

<Accordion disabled items={items} />;
```

### Closed panel retention

{"Closed panels unmount by default; keepMounted preserves internal state, while hiddenUntilFound retains searchable content for the browser find feature."}

```tsx title="showcases/accordion/cases/closed-panel-retention.tsx"
<Accordion items={items} />
<Accordion items={items} keepMounted />
<Accordion items={items} hiddenUntilFound />
```

## Component parts

- **Accordion** — Manage open values and render a set of related panels from items.
- **AccordionItem** — Describe one item’s identifier, title, panel content, and disabled state.
- **Accordion.Indicator** — Read the current item state and render an expansion indicator at the start or end of the title.

## Type definitions

### AccordionItem

```ts
type AccordionItem = {
  value: string;
  title: ReactNode;
  content: ReactNode;
  disabled?: boolean;
};
```

### AccordionIndicatorProps

```ts
type AccordionIndicatorProps = Omit<ComponentProps<'span'>, 'children'> & {
  children?: ReactNode | ((state: AccordionIndicatorState) => ReactNode);
  position?: 'start' | 'end';
};
```

### AccordionIndicatorState

```ts
type AccordionIndicatorState = {
  open?: boolean;
  disabled?: boolean;
  value?: string;
};
```
