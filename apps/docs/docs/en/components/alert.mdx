# Alert

{"Continuously display important in-page tips."}

## When to use

- Primary use: Continuously display important in-page tips.
- When you need to override the default, controlled, disabled and narrow screen states.

## Examples

<AlertShowcase />

### Basic usage

{"Alert is part of the page content; clicking the button conditionally displays an information, success, warning, or error banner instead of opening an overlay."}

```tsx title="showcases/alert/cases/basic-usage.tsx"
import { Alert } from '@heliannuuthus/ui';

<Alert
  variant="warning"
  icon={<TriangleAlert />}
  title="The rollback image will expire soon"
  description="Recommended to rebuild before publishing."
  action={<Button onClick={close}>Close</Button>}
/>;
```
